# Як долучитися до українського перекладу EU5

Дякуємо за інтерес до проєкту! Цей документ пояснює, як ви можете допомогти з перекладом Europa Universalis V українською мовою.

## Джерело перекладу

Переклад лежить у `translations/<root>/<шлях>.json`, де `<root>` = `main_menu` | `loading_screen`. Кожен
файл має вигляд:

```json
{
 "SOME_KEY": {
  "en": "Get $GOLD$ gold from [Country.GetName]",
  "uk": "Отримати $GOLD$ золота від [Country.GetName]"
 }
}
```

- Редагуйте **лише** поле `"uk"`. Поле `"en"` — оригінал з гри, за ним інструменти звіряють, чи не
  змінився текст у грі; не чіпайте його.
- Порожній `"uk": ""` означає неперекладений рядок — гра покаже англійський текст.

### Способи долучитися

1. **Fork** репозиторію (кнопка "Fork" у правому верхньому куті)

2. **Клонуйте** ваш fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/eu5-ukrainian-localization.git
   cd eu5-ukrainian-localization
   ```

3. **Створіть гілку:**
   ```bash
   git checkout -b translate/category-name
   ```

4. **Відкрийте** потрібний `.json` файл у `translations/` (VS Code, Notepad++ тощо) і перекладіть поле
   `"uk"` для потрібних ключів.

5. **Збережіть теги побайтово.** Розмітка гри — це спеціальні конструкції, які гра замінює на дані.
   Вони мають лишитися в перекладі точно в такому вигляді, як в оригіналі (можна переставити в реченні,
   не можна змінити чи видалити):

   ```json
   "en": "Отримати $GOLD$ золота від [Country.GetName]"
   "uk": "Отримати $GOLD$ золота від [Country.GetName]"
   ```

   Типи токенів:
   - `$VAR$`, `$VAR|формат$` -- змінні
   - `[Scope.Function]`, `[Scope.Func(...)]` -- скриптові виклики
   - `#tag ... #!` -- форматування тексту, тег обов'язково закривається `#!`
   - `\n` -- перенос рядка (як текст, не як символ)

6. **Перевірте локально**, якщо у вас встановлена гра:
   ```bash
   python uk.py check --lenient --game "C:\шлях\до\Europa Universalis V"
   ```
   або встановіть шлях у змінну середовища `EU5_DIR` і викликайте без `--game`. `check` звіряє
   розмітку побайтово і попереджає, якщо оригінальний текст у грі змінився після виходу оновлення.
   `--lenient` не вимагає точного збігу скриптових геттерів (`[X.GetName|U]` проти `[X.Custom('CL')|l]`)
   -- корисно для застарілих перекладів.

   Без гри цей крок пропустити не критично: рецензенти й CI звірять JSON-синтаксис і структуру
   автоматично.

7. **Закомітьте й відкрийте Pull Request:**
   ```bash
   git add translations/...
   git commit -m "translate: category-name"
   git push origin translate/category-name
   ```
   Потім створіть Pull Request на GitHub.

### Через Issues (без Git)

Якщо ви не хочете працювати з Git:

1. Відкрийте нову Issue на GitHub
2. Вкажіть файл, ключ, поточний текст та ваш переклад
3. Ми застосуємо зміни

## Правила перекладу

### Термінологія EU5

| Англійська | Українська |
|------------|------------|
| Estate | Стан (соціальний) |
| Subject | Васал / Підлегла держава |
| Overextension | Перенапруження |
| Core | Ядро |
| Claim | Претензія |

### Уникайте москалізмів

- "любий" -> "будь-який"
- "питання" -> "пита́ння" (наголос на А)
- Тощо -- перевіряйте себе

## Про файли з `_ru_` в назві

Файли з `customizable_localization_ru_*` у назві шляху -- це **НЕ** російська мова. `RU` -- це технічний
ідентифікатор Paradox для системи відмінків слов'янських мов:

| Суфікс | Відмінок |
|--------|----------|
| `_NOM` | Називний (хто? що?) |
| `_GEN` | Родовий (кого? чого?) |
| `_DAT` | Давальний (кому? чому?) |
| `_plural` | Множина (1 рік, 2 роки, 5 років) |

Назви файлів і ключів змінювати **не потрібно** -- гра шукає їх саме так. Перекладається лише вміст.

## Категорії файлів

Для уникнення конфліктів, оберіть одну категорію (шлях всередині `translations/main_menu/` або
`translations/loading_screen/`):

| Категорія | Папка | Опис |
|-----------|-------|------|
| Events DHE | `events/DHE/` | Динамічні історичні події |
| Events Character | `events/character/` | Події персонажів |
| Events Culture | `events/culture/` | Культурні події |
| Interfaces | кореневий рівень | Елементи інтерфейсу |
| Missions | `missions/` | Місії країн |
| Government | кореневий рівень | Урядові системи |
| Modifiers | кореневий рівень | Модифікатори |

**Перед початком:** перевірте Issues, чи категорія не зайнята іншим перекладачем.

## GUI редактор (застарілий)

`tools/localization_gui.py` редагує `.yml` файли мода напряму й не знає про `translations/*.json` --
джерело перекладу відтоді перенесено в JSON. Інструмент лишається в репозиторії, але для повʼязаного
перекладу непридатний: зміни в ньому не потраплять назад у JSON-джерело. Редагуйте `translations/*.json`
напряму, як описано вище.

## Чек-лист перед commit

- [ ] Редагували лише поле `"uk"`, `"en"` не чіпали
- [ ] Усі токени розмітки (`$VAR$`, `[Scope.Func]`, `#tag ... #!`, `\n`) на місці
- [ ] JSON лишився валідним (лапки та коми не зламані)
- [ ] Переклад граматично правильний
- [ ] Немає москалізмів
